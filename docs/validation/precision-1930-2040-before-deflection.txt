Precisão do motor natal entre 1930 e 2040
Validação de 16 de outubro de 2026

Foram corrigidas as séries VSOP87D, FK5, aberração anual/solar, a tabela e o referencial de Plutão, os nodos, Quíron, as velocidades e as casas polares. Nenhuma interpretação foi implementada.

Amostragem: 172174 instantes, 13 corpos, grade de seis horas + 10.000 instantes pseudoaleatórios + duas amostras explícitas. Comparações em UT e TT contra Swiss Ephemeris 2.10.03; backend SWIEPH confirmado em todas as chamadas. Os máximos abaixo são amostrais, não limites demonstrados para todos os instantes.

Todos os 13 corpos ficaram abaixo de 1 minuto de arco em longitude e latitude na amostragem. O maior erro longitudinal foi o da Lua, 18,249 segundos de arco.

Casas: 7.920 configurações. Maior erro não polar de cúspides/ASC: 0,855 segundo de arco. Nas regiões polares, Iguais/Whole Sign tiveram erro angular máximo de 0,969 segundo de arco; os 960 casos Placidus rejeitados pela Swiss também foram rejeitados pela API pública. Não restam as antigas inversões de 180 graus nesta grade.

Limites que permanecem
As diferenças de signo caíram de 17.568 para 8; as de retrogradação, de 85.907 para 26, sobre 2.238.262 avaliações corpo/instante. Oito diferenças de signo: Lua 5, Mercúrio 1, Netuno 1, Plutão 1. Retrogradação: Plutão 4 e nodo verdadeiro 22. Nenhuma amostra foi descartada.
O motor não implementa a deflexão gravitacional solar. Embora sua contribuição de posição seja de segundos de arco, sua derivada pode produzir diferenças grandes de velocidade muito perto de conjunções solares. O diagnóstico velocity-residuals.json mantém os piores casos e separa essa convenção. O nodo tabulado também não reproduz exatamente as variações numéricas de escala muito curta da Swiss. Não há equivalência exata entre os motores.
Quíron e nodo verdadeiro usam dados Swiss versionados e interpolação local, com geradores e hashes. Nesses dois casos a comparação verifica fidelidade dos dados/interpolação, não constitui validação de uma teoria astronômica independente. As aproximações fora das tabelas não herdam a precisão medida em 1930–2040.
A diferença máxima entre os modelos de delta T foi 13,458 segundos em 2040. Valores futuros são estimativas da rotação terrestre. A comparação em TT comum separa esse efeito das efemérides.

Verificação
npm test passou: 1.495 testes Rust/doc, 331 de interface, 80 de gráficos e 74 de relatórios (1.980 no total), além de mutações de interface/gráficos e verificações de documentação/licenças.
Os JSON atuais guardam erros, percentis, piores instantes, hashes e versões. Os arquivos *-before.json preservam a auditoria anterior. Os diagnósticos antigos de VSOP e Plutão estão identificados como históricos.

Reprodução (a partir da raiz do repositório)
1. Compilar o projeto com Rust 1.96.0, wasm-bindgen 0.2.129 e Node 24: npm run build.
2. node scripts/validation/export-core.mjs /tmp/celestial-core-audit.bin
3. python scripts/validation/compare-swiss.py --ephe DIRETORIO_DOS_ARQUIVOS_PINNED --input /tmp/celestial-core-audit.bin
4. python scripts/validation/houses-swiss.py --output /tmp/celestial-house-reference.json
5. node scripts/validation/houses-core.mjs --reference /tmp/celestial-house-reference.json
6. python scripts/validation/velocity-diagnostic.py --ephe DIRETORIO_DOS_ARQUIVOS_PINNED
O Python requer pyswisseph 2.10.3.2. O manifesto de efemérides está no JSON principal; os geradores não acessam a rede. O runtime Rust/WASM não exige Swiss instalada.
